# Interaction

Draft, 2026-11-21. A small grammar that's quick to learn: each input does one job.

| Input | Does |
|---|---|
| **AI button: hold** | Talk. Release to send. |
| **AI button: tap** | "About this": act on the plate on screen ("five more minutes"). |
| **Swipe left / right** | Move between plates: pinned, recent, now. A haptic detent at each plate. |
| **Tap** | The plate's one main action. |
| **Long-press** | Pin or unpin the plate. |
| **Flip face-down** | Mute and do-not-disturb. |
| **Tilt** | The orb leans toward you (subtle depth). |

## Principles

- **One thing at a time.** The screen shows one plate or the orb. No status bar, no app grid,
  no notification drawer.
- **Voice is the fast path, never the only path.** Everything can be done by touch.
- **Speak short, show the detail.** Spoken answers stay brief; the plate carries the rest.
- **Haptics are punctuation.** Short detents and a soft heartbeat while thinking. Never long buzzes.
- **Degrade gracefully.** A board without a mic gets tap-only plates; without a motor, visual detents.
