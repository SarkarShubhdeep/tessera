        Principles
        
Rules.

One accent

        Setup
        

          
What it runs on.

          
Every tool and service Tessera uses, and where to change it.

        

      

      

        
BoardESP-Mosaico v1.2
Pins and drivers in board.c. Every new pin gets a written review before flashing.

        
FirmwareC, ESP-IDF 6.1, LVGL 9.5
The UI uses only LVGL, so the same code builds for the board and the Mac.

        
SimulatorSDL2 on macOS
The 480 × 480 screen in a window. Build it with CMake and Ninja.

        
AnswersClaude, claude-opus-5-5, effort low
Model and effort in claude.c. Claude answers through one tool, show_plate.

        
SpeechGroq, whisper-large-v3-turbo
Any OpenAI-style transcription service: change two lines in groq.c.

        
KeysOn the device, never in the repo
Wi-Fi and both keys go in through a setup page: over the USB cable, or from a phone on a private hotspot the board shows as a QR code.

        
FlashingApp slot only, backup first
Factory partition table kept. A full flash backup restores the board.
