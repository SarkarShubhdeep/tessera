# Design

- `gallery/`: every plate and orb state as rendered by the firmware code (`ui/`) in the simulator.
  Regenerate with `SNAP_DIR` (see `sim/README.md`).
- `canvas/`: the design canvas source (one `.dc.html` artboard per screen, `canvas.json` for the layout):
  anatomy, tokens, all plates and the orb, matching the native renders.
- `screenshots/`: the landing page.
